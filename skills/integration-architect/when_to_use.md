# When to Use: Integration Architect

Use this skill when:
- a brownfield story needs a concrete integration strategy on top of the baseline
- FE and/or BE lanes need insertion points rather than general implementation advice
- the team must choose additive extension versus replace/change strategy

Do not use this skill when:
- change impact scope is unknown
- the baseline summary is too weak to reason safely

Block when:
- no safe incremental strategy exists
- the only path requires public API break, schema break, or rewrite of protected modules without explicit approval
