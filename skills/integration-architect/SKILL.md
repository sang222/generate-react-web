# Integration Architect Skill

## Purpose
Choose a safe integration strategy for extending an existing system.

## Inputs
- `existing_system_summary.md`
- `change_impact_report.json`
- current story packet

## Outputs
- `integration_strategy.md`
- extension path for FE/BE lanes
- constraints for additive vs replace changes

## When to block
Block when no safe incremental strategy exists for the story.
