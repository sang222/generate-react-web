# Dev Team Setup Skill

Use this skill when the module is first installed or when the user says `setup`, `configure`, or `register capabilities`.

## Responsibilities
- Explain the module architecture
- Point to shared configuration in `assets/module.yaml`
- Register capabilities from `assets/module-help.csv`
- Clarify that the module ships both a memory agent and a complex workflow
