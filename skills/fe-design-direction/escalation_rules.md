# FE Design Direction Escalation Rules

Block or escalate when:
- target platform is unknown
- there is no target screen/page/component
- brand-critical work lacks brand assets and fallback is not allowed
- existing project has no discoverable UI convention
- implementation would require a new UI framework without approval

Fallback allowed when:
- brief is vague but domain/context is known
- selected default direction can be justified as the lowest-risk option
