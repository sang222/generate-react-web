# FE Design Direction Checklist

- Is the visual thesis specific to the product/domain?
- Is hierarchy clear enough for implementation?
- Are tokens explicit and compatible with the project?
- Does the plan reuse existing components when available?
- Are loading/empty/error states mentioned when relevant?
- Are accessibility and responsive notes included?
- Does the direction avoid generic AI-looking UI patterns?
- If brief is vague, are 2-3 variants provided with a default selection reason?
