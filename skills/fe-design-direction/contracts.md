# FE Design Direction Contract

Required outputs:
- `design_direction.md`
- `design_tokens.json`
- `component_plan.md`

`design_direction.md` must include:
- visual thesis
- target user/context
- layout hierarchy
- typography direction
- color direction
- interaction/motion direction
- accessibility notes
- anti-slop constraints
- fallback selection reason when variants were needed

`design_tokens.json` must include:
- schema_version
- color
- typography
- spacing
- radius
- motion

`component_plan.md` must include:
- target route/screen
- component table
- data source per component
- reuse/new component decision
- state handling
- scope boundaries
- no fake API notes
