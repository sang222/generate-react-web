# FE Visual Review Checklist

- Does the implementation follow selected design direction?
- Is hierarchy clear?
- Is spacing consistent?
- Are typography and color consistent with tokens/project?
- Are interactions smooth but not excessive?
- Are loading/empty/error states acceptable?
- Is accessibility baseline met?
- Is there any generic AI slop?
- Does implementation stay inside scope?
- Is any framework/plugin misused decoratively?
