# FE Visual Review Skill

## Purpose
Review implemented FE output against selected design direction, tokens, component plan, and production constraints.

This skill acts as visual QA, anti-slop reviewer, and production UI quality gate.

## Operating Mode
- Compare implementation to design direction, not personal taste.
- Check hierarchy, spacing, typography, color, brand/project consistency, interaction quality, accessibility, and implementation fit.
- Produce `visual_review_report.json`.
- Generate retry prompt when issues are fixable.
