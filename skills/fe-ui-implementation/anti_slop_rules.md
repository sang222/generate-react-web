# FE Implementation Anti-Slop Rules

Do not use:
- decorative purple/pink gradients without design-direction reason
- glassmorphism as default
- random icon grids
- meaningless KPI cards
- fake avatars/testimonials/stats
- over-shadowed cards
- inconsistent spacing or radius
- animations that do not support user feedback

Use framework utilities to implement the design direction, not to decorate blindly.
