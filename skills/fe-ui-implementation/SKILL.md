# FE UI Implementation Skill

## Purpose
Implement production React or React Native UI from the selected FE design direction, design tokens, and component plan.

This skill must not invent visual style. It codes within approved scope and existing project conventions.

## Operating Mode
- Read `design_direction.md`, `design_tokens.json`, and `component_plan.md` before coding.
- Reuse existing components and styling conventions first.
- Produce implementation JSON with files and touched-boundary summary.
- Keep code maintainable, scoped, and compatible with build/test constraints.

## Non-Goals
- Do not fake APIs.
- Do not change routing/architecture without scope approval.
- Do not introduce a new CSS/UI framework without approval.
- Do not generate generic AI-looking UI.
