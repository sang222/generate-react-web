# FE UI Implementation Checklist

- Did you follow the selected design direction?
- Did you use the design tokens or existing project tokens?
- Did you reuse existing components when possible?
- Are touched paths inside allowed scope?
- Did you avoid fake APIs and fake stats?
- Is styling approach consistent with the project?
- Are loading/empty/error states implemented when required?
- Is the code maintainable and componentized?
- Did you avoid new heavy dependencies?
