# When to Use: Brownfield Analyst

Use this skill when:
- `project_mode = existing_project`
- the team needs a concrete summary of the delivered baseline or legacy codebase
- downstream roles need protected modules, fragile areas, and stack boundaries before planning changes

Do not use this skill when:
- the task is a pure greenfield story
- the baseline project does not exist yet
- the work is limited to a trivial copy-only change that does not touch code structure

Block when:
- stack, module ownership, or protected areas cannot be identified with enough confidence
- the story scope touches unknown legacy code and the summary cannot make it safe
