# Review Examples

## Structural bug example
- "Catalog route was added, but the generated backend build file is missing, so the backend lane is not buildable."

## Functional bug example
- "Story requires product detail, but no detail route or endpoint exists."

## Regression bug example
- "Shared layout navigation was rewritten and removed an existing order history link from the baseline."

## Good fix suggestion example
- "Preserve the current layout, add a dedicated catalog route, and keep backend changes limited to a new catalog controller/service/repository set."
