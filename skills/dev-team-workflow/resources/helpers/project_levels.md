# Project Levels
- Level 0 (micro): tiny task, minimal files, prefer a single small delivery slice.
- Level 1 (small): simple story, keep architecture very light.
- Level 2 (standard): normal story delivery with practical architecture.
- Level 3 (large): stronger gating, baseline protection, and multi-lane discipline.
- Level 4 (enterprise): strict workflow, richer artifacts, and stronger coordination expectations.
