# Architect Sizing Guidance
- Level 0-1: prefer a minimal extension plan and a very small file tree.
- Level 2: define practical frontend/backend boundaries, validation points, and implementation notes.
- Level 3-4: explicitly identify module boundaries, shared contracts, protected modules, ownership constraints, and integration checkpoints.
- For existing_project stories, design additive changes first; avoid replacing stable baseline structures unless the story requires it.
